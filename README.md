# CodeSkill.AI - Landing Page
A clean, responsive dark-mode landing page for CodeSkill.AI, built with React, Vite, and Tailwind CSS.

# Live Demo 
**(https://landing-page-kx0q.onrender.com/)**

## 🛠️ Built With
- **React** (Frontend Framework)
- **Vite** (Build Tool & Dev Server)
- **Tailwind CSS** (Styling)
- **Lucide Icons**
--
## 🛠️ Prerequisites
Make sure you have **Node.js** (v18 or higher) and **npm** installed on your system.
* [Download Node.js](https://nodejs.org/)
